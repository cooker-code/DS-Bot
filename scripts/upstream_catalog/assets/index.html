依赖组是什么意思？

把同一功能、需要配套适配或验证的 PR 归到一组，方便安排处理顺序。

例如 G16 是“设置导航、搜索与组件入口”。

同组不等于必须全部合入；具体前置关系和处理顺序，请看各 PR 的原因与完整解决方式。
