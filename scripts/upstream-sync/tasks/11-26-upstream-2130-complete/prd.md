# 完整适配 PR2130 协作流程

## 目标
在独立分支完整适配插件适用的 Call & Return 生命周期。基线 4ad540b1，dev 7b9a4fa8 只读。来源 PR2130 94aa5a451，后续固定端点 bb1b159247 的相关加固参与核对。

## 需求与用户可见结果
1. 正式项目派工和辅助委托都能追问、答复、返回结果，保持 taskId、dispatchId、原会话；不会自动提交或批准项目卡。
2. Bot 忙碌时 now 使用独立会话，queue 顺序执行；手动并行会话、新建和切换保留。
3. 追问或无进展循环暂停，界面可继续和取消；取消子树后迟到结果不再唤醒，无关卡继续。
4. note、取消和停止通知静默，忙碌时缓冲，下一次正常输入可读；不产生 ACK 回环和空泡。
5. SQLite 和 inflight 恢复保存完整归属，等待和暂停不自动执行；结果投递可恢复且不重复。
6. 完整验证和独立验收后，从本分支打包安装 web/desktop，更新上游唯一来源条目、验证与版本记录，不合 dev。
