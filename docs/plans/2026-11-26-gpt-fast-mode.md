# GPT 模型快速模式

- 日期：2026-11-26
- 相关：[模型批量选择](2026-11-13-bot-models.md)

## 为什么

DSH 当前没有将 OpenAI 的 service_tier 暴露为可配置请求参数。用户需要在 DS Bot 模型设置中申请 GPT Fast 加速，同时保留现有模型、思考强度和 DSH 的协议适配。

## 已定的行为

- 在模型设置的供应商展开区域，对使用 OpenAI Chat Completions 或 Responses HTTP 协议的 GPT 模型提供快速模式开关，包含 openai/gpt- 开头的模型 ID。本地 Agent 与其他协议不显示。
- 开关按供应商及模型 ID 保存，影响使用该供应商和模型的所有请求。开启时发送 service_tier=fast；关闭后恢复原请求行为，供应商自己的默认档位仍有效。
- 页面说明 Fast 增加费用、供应商可能采用标准处理。开关表示已保存的请求偏好，不表示上游实际使用了 Fast。
- DS Bot 管理仅监听本机回环地址的 HTTP 转发，通过 DSH 公开 settings 接口修改供应商 baseURL，保存原用户层地址。请求携带原密钥前往固定上游，插件不另存或打印密钥。DSH 继续负责协议、消息转换和响应解析，插件修改选中模型请求正文的服务档位。
- 模型发现和未开启模型经过转发时维持原行为。流式回复、工具、图片和上游错误继续传递；取消关闭对应上游连接。
- 启用状态保存在团队 SQLite 的扩展字段 modelFast，宿主重启或接管团队写锁时重新绑定端口并更新地址。失去写锁时恢复并退役本进程管理的地址；同一状态的通知不会重复重连。全部关闭或插件正常停用时恢复原地址；已经在处理的请求保留其已发送的档位，流式回复结束后释放空闲上游连接；最后一个开关关闭时停止接收新连接。
- 用户在 DSH 更改供应商地址后，插件不覆盖该地址，提示关闭后重新开启。异常退出后再次加载插件会恢复连接；停用或移除插件前应先关闭快速模式。
- 单个 HTTP 请求正文上限为 64 MiB；显式 WebSocket 传输不提供开关。

## 不做什么

不修改 DSH 源码、安装文件、模型 ID 或思考强度，不管理本地 Codex CLI 的速度档位，不安装其他社区插件。

## 已知限制

供应商必须支持 Fast 参数。中转站可能拒绝、忽略或改写它；Fast 请求也可能回落到标准处理。Fast 开关不对实际速度、费用或模型能力作承诺。供应商路由启用转发后，该路由的其他模型也经过同一本机服务，但不会被写入 Fast 参数。
