# 目标

1. 查看任务往来时能理解实际含义，随时核对完整模型输入输出。

# 需求

- R1：「原文」改为「人话」，Markdown 保留完整输入输出。
- R2：用户选择按需解释，点击时生成并保存，下次查看复用，旧记录可用。
- R3：依据用户明确阅读要求，先说结论和实际动作，解释必要术语，保留限制、未知与依据。
- R4：保留原文、并行输出归属和历史含义，失败可重试且 Markdown 可读。
- R5：人话 Prompt 可在设置中编辑、保存和恢复默认，保存后按新 Prompt 生成解释。
- R6：说明解释使用发送方 Bot 的基础模型，以及接收方、管理员和默认模型的回退规则。

# 用户可见结果

- [x] O1（R1）：输入和各份输出可切换人话与 Markdown，原文及复制内容逐字保留。
- [x] O2（R2）：首次点击才生成，重复查看和宿主重启复用保存结果。
- [ ] O3（R3）：解释规则与路由已核实；实际措辞是否易懂由用户使用真实模型验收。
- [x] O4（R4）：并行输出各自展示；失败可重试，不完整源与跨卡请求被拒绝。

- [ ] O5（R5）：设置 → 提示词可编辑、保存和恢复默认，刷新和重启后保留；提示词变化让旧解释失效。
- [ ] O6（R6）：设置页可读到模型选择说明，与发送方、接收方、管理员及默认模型调用路径一致。
