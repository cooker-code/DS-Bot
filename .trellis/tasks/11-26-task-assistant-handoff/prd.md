# 任务助理交接失败与旧卡接续

## Goal

1. 已接单的原卡不会因交接失败或助理任命变更而无人接续。
2. 管理员主动扫描未分配原卡，说明未发送原因并安全重试；用户无需反复催促。

## Requirements

- R1：接单保存整理后的标题、需求和验收；交接失败保留正文及失败依据。
- R2：管理员能查看未分配原卡的实际原因与是否可重试，并从本群管理会话沿原卡重试。
- R3：任命、更换助理及重载后自动通知管理员扫描尚未交接的卡；保持在途计划及执行轮次。
- R4：核对真实投递记录，避免重启、重复调用或不确定发送结果造成重复交接。

## User-visible Outcomes

- [ ] O1（R1）：发送失败后卡片正文仍完整，能说明失败原因。
- [ ] O2（R2）：管理员能沿同一卡号重试并取得真实交接回执。
- [ ] O3（R3）：先接单后任命助理，管理员自动发现并继续原卡。
- [ ] O4（R3、R4）：已有开发不被重新派发；重启及重复重试只交接一次。

用户于本会话明确批准修复及隔离验证；最新补充要求由管理员扫描和重试，不通过操作者向群发送临时推进指令。
