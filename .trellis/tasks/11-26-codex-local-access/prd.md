# 后门（Backdoor）：Codex 本机受限访问 DS Bot

## Goal

1. 用户继续从 Dock 使用 Desktop，Codex 可以查询 DS Bot 团队、项目卡并修改 Bot 简介和群公告。
2. 接入权限仅覆盖上述 DS Bot 操作，不交出整个 DSH 的登录凭据。

## Requirements

- R1：默认关闭，通过本机命令明确启用、查看状态和撤销；已有新版宿主无须重启即可响应启停。
- R2：Unix socket 仅向当前 macOS 账户开放，不建立 TCP 监听，不处理 DSH Token/Cookie。
- R3：仅允许团队/项目卡查询、Bot 简介和群公告修改；额外动作与字段必须拒绝。
- R4：修改复用原业务校验、团队写锁和持久化；按 ID 全文回读保存结果。
- R5：撤销后阻止尚未进入业务服务的请求；宿主正常退出清理本次监听和发现文件。重启后按原授权选择恢复，新连接不得落到旧宿主。
- R6：文档明确权限识别当前操作系统账户，不能区分同账户的 Codex 与其他程序。日用安装、合入 dev 和发布另行安排。

## User-visible Outcomes

- [x] O1（R1、R2）：默认关闭；启用命令返回实际活动状态；过程中没有 DSH 登录材料或新增 TCP 监听。
- [x] O2（R3、R4）：团队和项目卡查询可用；中文多行简介与公告保存后按同一 ID 全文一致。
- [x] O3（R2、R3）：额外修改模型/权限及 DSH 接口被拒绝；不安全文件权限、符号链接、错误写锁 PID 和只读宿主不能越权。
- [x] O4（R1、R5）：撤销后新请求失败，重新启用恢复；正常退出清理 socket、发现文件及测试进程。
- [x] O5（R6）：帮助与契约说明账户范围、命令、副作用和安装状态，未把功能分支验证说成日用已加载。
