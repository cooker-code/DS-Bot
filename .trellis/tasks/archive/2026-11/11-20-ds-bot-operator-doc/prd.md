# DS Bot 设置契约、岗位能力与项目进度查询

## 目标

1. 提供按业务、服务和数据层可追溯的程序化设置，校验岗位绑定和单群 task 读取。

## 需求

### R1 新增

- **R1.1 程序化设置契约** 从业务动作追到操作者 API 的入参、出参、服务、实际存储和生效方法。新增或修改接口时同步维护契约。
- **R1.2 可复用岗位** 管理员可复用岗位简介创建 Bot，也可仅给已有 Bot 增加技能。保留该 Bot 的其他配置，支持中断后继续。
- **R1.3 按群检查进度** 查询指定群的 task 积压无需读取全队资料。保留与团队总览一致的状态、负责人和轮次语义，收件另计。

### R2 边界

- **R2.1 实例与锁** 查清本机日用宿主的合法登录入口。隔离验证 API 配置、SQLite 只读核查和停机副本操作，分别说明日用团队的实际保存状态。

## 用户可见结果

- [x] **O1（R1.1、R2.1）** 在仓库 AGENTS.md 能找到 ds-bot-doc，从一份契约中定位宿主、权限、参数、返回值、表和锁。接口名覆盖检查能发现遗漏。
- [x] **O2（R1.2）** 操作者可按需应用十二种通用岗位，或保留定制介绍仅补技能。重复执行后可回读同一个 Bot ID 和唯一技能绑定。
- [x] **O3（R1.3）** 能按指定群查看 task 状态与待处理收件。空群返回空数组，查错群得到明确错误，只读宿主仍可查询。
- [x] **O4（R2.1）** 交付记录区分日用已保存的资料、隔离宿主验证、待完成的正式绑定和已加载的插件版本。[验证与日用状态](report.md)
