# 实施与核验

1. 以插件分派器、服务及分库 schema 编制 ds-bot-doc。在 AGENTS.md 约定维护方式，操作名覆盖脚本检查漏项和重复记录。
2. 由操作者脚本传递合法会话，仅输出指定结果。岗位脚本按 ID 或明确的唯一名称创建、更新和回读。
3. 为目标群读取复用现有摘要。用隔离测试覆盖两个群的数据隔离、空集合、轮次负责人、待处理收件、未知群和只读宿主。
4. 在隔离的 DSH Web 创建十二个岗位、导入技能、补绑定、修改群成员覆盖。重启后按稳定 ID 回读，和三类 SQLite 库核对。在停机副本验证完整性、事务回滚和错误路径。
5. 独立记录日用宿主的资料、技能及持锁状态。安装包和运行实例分别核对；涉及正在运行的用户会话，按真实交接授权操作。
