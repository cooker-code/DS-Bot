# 执行计划清单与项目逐题补充

## 目标

1. 用户从清单看清已完成、正在执行和待办工作，计划演进保留有效成果。
2. 用户逐题补齐需求，答案回到原任务并由明确的 Bot 续办。

## 需求

### R1 执行计划

- R1.1 默认清单展示动作、负责人、状态和完成数量，展开详情与历史比较。
- R1.2 改版保留稳定工作项，沿用仍有效的核验和在途轮次；范围或依赖改变时重新处理受影响部分。

### R2 逐题补充

- R2.1 输入框上方一次显示一题，支持选项和自由文本，逐题持久保存，普通聊天不清除问题。
- R2.2 答案由本群管理员和任务助理接收，保持原卡，分别显示保存、送达和正式开工证据。
- R2.3 纳入上游 PR #2014 的来源 IM 群卡与简单表单答复；项目问题默认由原提出人回答，自由文本使用显式 /answer。保留项目验收和并行会话规则。

## 用户可见结果

- [x] O1（R1.1/R1.2）新版清单保留有效完成项，重排后执行和问题均关联正确工作项。
- [x] O2（R2.1/R2.2）逐题回答、刷新和重启不丢答案，同一任务继续推进，重复点击不重复派发。
- [x] O3（R2.3）卡片只回来源 IM 聊天；错误群、连接、用户与过期按钮拒绝，正确回答回原 Bot。

用户于本会话先批准交互方案，再明确授权新建分支实施；随后明确将 PR #2014 纳入。采用原有产品主题与问题卡，不新建视觉原型或账号系统。实际界面与资源清理证据记录在验收回执。
