# 企微私聊绑定 DS Bot 群

1. 用户可在设置 → IM → 企业微信连接 → 聊天中，给已有私聊单独选择 DS Bot 群。
2. 用户私聊机器人后，正文进入所选群，本轮群成员回复回到原企微私聊，其他私聊继续使用各自的目标。
3. 选择「使用连接的 Bot」后，后续消息恢复投递到连接的对话对象。

## 独立验收回执

候选提交 `ca295b5f`，隔离验证通过。

1. 在设置页组件中打开企微私聊菜单并点击目标群，实际提交该私聊的 chatKey 和所选 roomId。

3. 点击「使用连接的 Bot」实际提交同一 chatKey 和空目标，模拟私聊的下一条消息进入默认 Bot 会话。
