# 企微私聊绑定 DS Bot 群

1. 用户可在设置 → IM → 企业微信连接 → 聊天中，给已有私聊单独选择 DS Bot 群。
2. 用户私聊机器人后，正文进入所选群，本轮群成员回复回到原企微私聊，其他私聊继续使用各自的目标。
3. 选择「使用连接的 Bot」后，后续消息恢复投递到连接的对话对象。

## 2026-11-23 企微私聊收不到群回复的补录

现场观察：16:03 的企微消息进入「数据开发」群，16:04 小圈在群内生成回复，用户在原企微私聊中未见回复。缺少当次请求对应的发送记录和网关回执，无法还原该条消息停在哪一步。

已复现的协议缺陷：旧适配器把同一私聊最近一次入站请求编号当作群成员延迟回复的编号，写出回调帧就结束发送。第二条入站消息会覆盖第一条的编号。主动发送分支还把私聊收件人写入 userid 字段，企微要求把用户 ID 放进 chatid。

上次漏测有两个原因。群路由测试用记录调用的假适配器替换了实际企微适配器，验证止于收件人选择。独立的协议测试只检查发出过回调帧，模拟服务对主动发送一律应答成功，也没有执行用例标题声称覆盖的回调窗口结束场景。两组测试之间没有用同一条群回复贯穿，90 项通过不能证明企微接受了该回复。

本次回归使用真实适配器连接本地网关，走完私聊入站、群成员发言和定向回传。协议用例另检验连续入站后回复、错误地址格式被拒、无关回执不能完成发送、同请求成功回执、平台拒收和回执前断线。旧实现在新用例中因未按 chatid 主动发送而失败。模拟网关接受与真实账号收到分别记录。
