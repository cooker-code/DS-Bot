# 用户已批准的文字交互范围

上一轮方案：增加“社区新功能与设计”入口，按功能说明用途、场景、限制、上游实现阶段、本地采用状态及暂缓原因，附设计原文与PR；PR详情增加相关设计说明、变更和固定版本链接。

本轮用户明确批准：“可以，把‘社区新功能与设计’入口和 PR 详情里的设计说明都补上，展示用途、使用场景、上游实现阶段、本地采用状态及暂缓原因，附设计原文和 PR 链接，并纳入 SQLite 增量同步。继续在独立分支做，不动 dev，验证通过后更新网页和 skill，把结果记录到 upstream-changelog.md。”

目标：“方便我知道upstream中新增更改了哪些功能，辅助判断是否加入自己的代码。”本记录仅归档该文字范围批准，布局实现与最终截图仍需实际验证，不代表最终用户验收。
