# GPT 模型 Fast 开关

## Goal

1. 在 DS Bot 模型设置中为通过 API 接入的 GPT 模型提供 Fast 开关。
2. 使用公开 DSH 插件接口与插件本机转发，不改 DSH 源码或安装文件；验证后合并 dev。

## Requirements

- R1 按供应商和模型 ID 保存 Fast 开关；开启写 service_tier=fast，关闭恢复原请求行为，保持模型和思考强度。
- R2 复用现有模型设置、开关与错误提示，说明费用、供应商可能回落、影响范围和关闭语义；非 GPT 与本地 Agent 不显示。
- R3 转发保留工具、图片、流式回复和上游错误，支持取消；GET 模型发现仍可用。
- R4 开关持久化，重启重建本机地址；全部关闭或插件停用恢复原供应商地址，清理服务和连接。
- R5 完成针对性测试、构建、lint、接口文档检查、隔离冒烟和独立只读验收后合并 dev。

## User-visible Outcomes

- [x] O1 对应 R1/R2：模型设置可开启和关闭指定 GPT 模型 Fast，其他模型保持原行为，错误不会显示已保存。
- [x] O2 对应 R1/R3：上游捕获请求参数正确，回复、工具、图片、错误和取消正常。
- [x] O3 对应 R4：设置跨重启恢复，停用恢复供应商地址，测试资源退出。
- [ ] O4 对应 R5：固定候选通过独立验证，合入 dev，保留其他已有修改。

自动验证与独立回执见 [verification.md](verification.md)。
